# MuvalCollege Website

## Project overview

This is a simple static college website for **Shri Janki Vallabh Arts & Shri M. C. Patel Commerce College, Muval**. The site is built with HTML and CSS only, making it easy to open locally in any browser.

## Root structure

- `index.html` - Main website page with content sections for Home, About, Management Trust, and Contact.
- `css/` - Stylesheet folder.
  - `styles.css` - Main responsive CSS for layout, typography, navigation, and page sections.
- `graphic/` - Image assets used by the site.
  - `hero.svg` - Hero illustration shown on the home section.
  - `hero1.png` - Favicon / icon asset.
- `uploads_file/` - Supporting documents and uploaded files.
  - `Newspaper_ad.jpeg` - Advertiser thumbnail linked from the announcement section.
  - `Form.pdf` - Application form linked from the announcement section.

## Key features

- Responsive layout using CSS Grid and media queries.
- Mobile-friendly navigation and content stacks.
- External links with safe `target="_blank"` usage.
- Embedded Google map for the college location.
- Simple structure that is easy to maintain and extend.

## How to use

1. Open `index.html` in a browser.
2. Edit content directly in `index.html` for text changes.
3. Update styles in `css/styles.css` for layout or design changes.
4. Replace image assets in `graphic/` and links in `index.html` if needed.

## Notes

- This project does not use JavaScript or server-side code.
- The site is best viewed in modern browsers but uses standard HTML & CSS for broad compatibility.
- If you add new pages, link them from the `index.html` navigation and keep assets organized in the appropriate folders.
